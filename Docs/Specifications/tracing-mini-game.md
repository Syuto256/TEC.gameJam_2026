# なぞるミニゲーム仕様

> **ステータス: 個人用デバッグ実装済み（2026-08-03）**  
> 企画: [ゲーム企画概要](../GameDesign/game-overview.md) / 共通ルール: [コアゲームプレイ仕様](gameplay-core.md)

## 1. 適用範囲

本仕様は、表示された経路をマウスでなぞって終点へ到達する、個人用のなぞるミニゲームを定義する。本編のタスク生成、AI 代行、HP・スコア計算は対象外とし、実装時は `MiniGameBase` の完了通知を通じて成否だけを返す。

単体確認用のシーンは `Assets/Personal/Suzuki/SuzukiTracingDebug.unity` とする。`TracingMiniGame` を 1 つ配置し、実行時に `Screen Space - Overlay` のデバッグ UI を構築する。

## 2. 入力

- Unity の New Input System（`UnityEngine.InputSystem`）を使用し、旧 Input Manager API には依存しない。
- 左クリックを押している間だけ、ポインタ位置をなぞり入力として判定する。
- なぞりは開始点からのみ開始できる。
- 左クリックを離した場合、その試行の進行を破棄して開始点からやり直す。ミス数は増やさない。

デバッグ実装では、開始点の判定半径を 36px とし、開始点以外で左クリックを押した場合は無視する。これらの値は Inspector で調整可能である。

## 3. 成功・ミス・失敗

| 事象 | 処理 |
| --- | --- |
| 開始点から左クリックを押す | なぞり試行を開始する。 |
| 判定中に経路から許容距離を超える | 即座に 1 ミス。試行を開始点へリセットする。 |
| 左クリックを離す | 試行を開始点へリセットする。ミス数は維持する。 |
| ミス数が 2 回に到達 | `FinishGame(false, "MISSED")` を一度だけ通知する。 |
| 終点に到達 | `FinishGame(true, "COMPLETE")` を一度だけ通知する。 |
| 制限時間切れ | `MiniGameBase` により `FinishGame(false, "TIME OUT")` を一度だけ通知する。 |

成功判定は終点への到達のみとする。なぞった距離、所要時間、経路上の精度を得点や追加条件には使用しない。

## 4. 経路と判定

- 画面上に開始点、終点、なぞる対象の経路を 2D UI として表示する。
- 入力中のポインタ位置と経路の最短距離を毎フレーム判定する。
- 最短距離が許容距離以内なら継続し、超過したフレームで即ミスとする。
- 難易度は、主に経路の形状・長さ・線幅・許容距離で調整できるようにする。

デバッグ実装では、折れ線で構成した S 字経路を用いる。許容距離は 34px、開始点・終点の判定半径は 36px、制限時間は 20 秒とする。これらはプレイテスト用の初期値であり、Inspector から調整可能である。

## 5. UI

単体デバッグ画面は `Screen Space - Overlay` の 2D Canvas とし、少なくとも次を表示する。

| 表示 | 内容 |
| --- | --- |
| 経路 | なぞる対象の線。 |
| 開始点 / 終点 | なぞり開始位置と成功位置。 |
| ミス数 | `0 / 2`、`1 / 2` 等。 |
| 残り時間 | `MiniGameBase.TimeRemaining`。 |
| 結果 | 成功・失敗理由。完了時に表示する。 |

デバッグ実装では、なぞり入力中の現在ポインタ位置だけを水色のマーカーで表示する。軌跡の常時表示、演出、音響は未実装とする。

## 6. 確認項目

1. 開始点から左クリックを押した時だけ、なぞり判定が始まる。
2. 左クリックを押している間、許容距離内の移動では試行を継続できる。
3. 許容距離を超えるとミス数が 1 増え、開始点からやり直しになる。
4. 左クリックを離すと、ミス数を増やさず開始点からやり直しになる。
5. 2 回目のミスで失敗が 1 回だけ通知される。
6. 許容距離内で終点へ到達すると成功が 1 回だけ通知される。
7. 制限時間切れが 1 回だけ通知される。

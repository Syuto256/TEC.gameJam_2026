# タイピングミニゲーム仕様

> **ステータス: 本番移植前の合意済み仕様（2026-08-03）**
> 既存の個人用デバッグ実装を原本として保全し、本番実装は共有領域に新規作成する。

企画: [ゲーム企画概要](../GameDesign/game-overview.md) / 共通ルール: [コアゲームプレイ仕様](gameplay-core.md) / 接続: [メインゲーム画面・接続仕様](main-game-flow.md)

## 1. 適用範囲

本仕様は、タスクを自力開始した際に実行する日本語ローマ字タイピングミニゲームを定義する。`TypingMiniGame` は `MiniGameBase` を継承し、成功・失敗を 1 回だけ共通イベントで返す。本編のタスク寿命、AI、HP、スコアは [コアゲームプレイ仕様](gameplay-core.md) が扱う。

## 2. 問題データ

本番用の `TypingQuestionDatabase` ScriptableObject を `Assets/Data/MiniGames/Typing/` に置き、レベル別の問題一覧を保持する。個人用の `TypingWordDatabase` とそのアセットは編集・移動しない。

| 項目 | 型 | 例 | 説明 |
| --- | --- | --- | --- |
| QuestionId | string | `typing-low-assign` | 重複出題抑止とデバッグに使う識別子。 |
| 表示文字列 | string | `アサイン` | 画面に表示するお題。漢字・かな・英字を含めてよい。 |
| 読み | string | `あさいん` | ローマ字候補生成に用いるひらがなの読み。 |
| 問題レベル | 1–4 | `1` | 出題対象を決める。 |

- レベルと同じ問題レベルからランダムに 1 件選ぶ。直前の `QuestionId` は候補から除外する。
- 対象レベルに有効な問題がない場合は設定不備とし、`NO QUESTION CONFIGURED` で 1 回だけ失敗する。別レベルへの自動フォールバックはしない。
- 各レベルは初期版で最低 8〜10 問を用意する。受領仕様書のお題例を初期候補とする。

> TODO（2026-08-03）: 各レベルに採用する最終問題、問題数、語彙の重複方針は M4 の問題データ作成時に決め、プレイテストで見直す。

## 3. 入力とローマ字判定

- 正解入力は英字キーとし、大文字・小文字は区別しない。
- 入力は Input System の `Keyboard.onTextInput` を使用し、旧 Input Manager API には依存しない。
- 読みから複数の許容ローマ字候補を生成する。訓令式・ヘボン式を含む一般的な表記ゆれを許容する。
- 初期実装から `し`、`ん`、促音（っ）、拗音（きゃ等）に対応する。
- 入力済み文字列を接頭辞に持つ候補が 1 件以上あれば正解入力とする。候補がないときだけ誤入力とする。
- 誤入力では正しく入力済みの進捗を戻さない。0.2 秒の入力無効後、同じ位置から再入力する。

> TODO（2026-08-03）: 外来語、記号、濁点分離を含む許容表の詳細は、実際の問題リストに対するテストとともに追加する。

## 4. ミスと終了条件

| 事象 | 処理 |
| --- | --- |
| 誤キー入力 | ミス数を 1 増加し、0.2 秒の入力無効を開始する。 |
| 入力無効中のキー | 完全に無視する。 |
| ミス数が 2 | `FinishGame(false, "MISSED")` を 1 回だけ通知する。 |
| 制限時間切れ | `MiniGameBase` により `FinishGame(false, "TIME OUT")` を 1 回だけ通知する。 |
| 全候補で入力完了 | `FinishGame(true, "COMPLETE")` を 1 回だけ通知する。 |

失敗後の再挑戦は行わない。本編は失敗結果を受けて HP を減少させる。

## 5. レベル設計

| レベル | 問題の方針 | 例 |
| --- | --- | --- |
| 1 | 短い単語、一般的なローマ字 | アサイン、コミット、プル、おにぎり |
| 2 | 促音・拗音を含む中程度の単語 | ガチャガチャ、望遠レンズ、アルゴリズム |
| 3 | 長い単語、複雑な音節 | サグラダファミリア、シンギュラリティ |
| 4 | 文、長い外来語、記号を含む表示 | 行く春を惜しむこのごろです、アーティフィカルインテリジェンス |

問題レベルはゲーム難易度とは別である。ゲーム難易度からの出題範囲は [ゲーム企画概要](../GameDesign/game-overview.md) を正とする。制限時間は `MiniGameCatalog` と `GameTuningSettings.miniGameTimes.typing` で調整する。

## 6. UI

`MiniGameHost` 配下の Canvas UI Prefab として表示する。基準解像度は 1920×1080 である。

| 表示 | 内容 |
| --- | --- |
| お題 | 表示文字列。 |
| ローマ字表記 | 代表候補。唯一の正解ではない。 |
| 入力済み / 残り | 現在の進捗。 |
| ミス数 | `0 / 2`、`1 / 2`。 |
| 残り時間 | ミニゲーム制限時間。 |
| 結果 | 成功または失敗理由。 |

## 7. 原本からの移植

- `Assets/Personal/Suzuki/TypingMiniGame/` と `Assets/Personal/Suzuki/Suzuki.unity` は原本として編集しない。
- 本番用コードは `Assets/Scripts/MiniGames/Typing/` に新しいクラス名で作成し、既存のローマ字生成・入力判定のロジックを移植する。
- 本番用データと Prefab は `Assets/Data/MiniGames/Typing/` および `Assets/Prefabs/MiniGames/Typing/` に置く。
- 本番用の Unity アセットを個人領域のアセットから作る場合は、Unity Pipeline の `copy_asset` で複製してから編集する。

## 8. 確認項目

1. 問題レベルに一致する問題だけが出題され、直前の問題を連続出題しない。
2. `しんぶん` などで複数の許容表記を最後まで入力して成功できる。
3. 誤入力 1 回で進捗を保ったままミスが増え、0.2 秒中の入力が無視される。
4. 2 回目のミスと時間切れが、それぞれ 1 回だけ失敗を通知する。
5. PC / パッドを切り替えても、起動済みタイピングの状態と共通のゲーム状態が矛盾しない。
6. 日本語 IME が有効な環境と無効な環境でローマ字入力を確認し、`Keyboard.onTextInput` が期待どおり英字を渡さない場合は物理キー入力方式へ切り替える。

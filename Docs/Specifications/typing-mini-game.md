# タイピングミニゲーム仕様

> **ステータス: 個人用デバッグ実装済み（2026-08-03）**  
> 企画: [ゲーム企画概要](../GameDesign/game-overview.md) / 共通ルール: [コアゲームプレイ仕様](gameplay-core.md)
> 実装: [クラスカタログ](../Architecture/class-catalog.md)

## 1. 適用範囲

本仕様は、タスク選択後に実行する日本語ローマ字タイピングミニゲームと、その単体デバッグ環境を定義する。本編のタスク生成、AI 代行、HP・スコア計算は対象外とし、ミニゲームは `MiniGameBase` の完了イベントを通じて成否だけを返す。

## 2. 問題データ

`TypingWordDatabase` ScriptableObject はお題一覧を保持する。1 件の `TypingWordEntry` は次を持つ。

| 項目 | 型 | 例 | 説明 |
| --- | --- | --- | --- |
| 表示文字列 | `string` | `新聞` | 画面にお題として表示する文字列。漢字・かなを含めてよい。 |
| 読み | `string` | `しんぶん` | ひらがなで保持する正規化前の読み。ローマ字候補の生成元。 |
| 出現難易度 | enum | `Easy` | 出題時の難易度フィルターに使う。 |

表示用ローマ字はデータとして持たず、読みから生成する。デバッグ環境では選択難易度に一致するお題からランダムに選ぶ。対象が 0 件の場合は開始せず、設定不備をログ出力する。

## 3. 入力とローマ字判定

- 正解入力は英字キーとし、大文字・小文字は区別しない。英字以外の入力可能文字は正解にならないため、誤キー入力として扱う。
- 実装は Input System の `Keyboard.onTextInput` を使用する。旧 Input Manager API には依存しない。
- 読みから複数の許容ローマ字候補を生成する。候補には、訓令式・ヘボン式を含む一般的な表記ゆれを可能な限り含める。
- 初期実装から `し`、`ん`、促音（っ）、拗音（きゃ等）に対応する。
- 各キー入力後、その入力済み文字列を接頭辞に持つ候補が 1 件以上あれば正解入力とする。候補がない場合にのみ 1 ミスとする。
- 正解入力済みの位置はミスによって戻さない。無効時間終了後は、同じ位置から再入力する。
- 全候補で入力が完了したら成功とする。

> TODO（2026-08-03）: 特殊な外来語・記号・濁点分離などを含むローマ字許容表は、実際の出題リスト作成時に追加・検証する。

## 4. ミスと終了条件

| 事象 | 処理 |
| --- | --- |
| 誤キー入力 | ミス数を 1 増加し、0.2 秒の入力無効を開始する。 |
| 入力無効中のキー | 完全に無視する。進捗・ミス数を変更しない。 |
| ミス数が 2 | `FinishGame(false, "MISSED")` を一度だけ通知する。 |
| 制限時間切れ | `MiniGameBase` により `FinishGame(false, "TIME OUT")` を通知する。 |
| 読みの入力完了 | `FinishGame(true, "COMPLETE")` を一度だけ通知する。 |

失敗後のタスク再挑戦は行わない。本編は失敗結果を受けて HP を減少させる。

## 5. 時間と難易度

難易度は出題候補のフィルターに用いる。難易度調整の主軸は問題内容とし、ミニゲームの制限時間はデバッグ用および将来調整用に Inspector から変更可能にする。難易度別の正式な時間設定は未確定である。

## 6. UI

日本語表示可能な TextMeshPro フォントを後から割り当てられる前提とする。デバッグ環境は `Screen Space - Overlay` の 2D Canvas を使用し、各表示欄は `TextMeshProUGUI` とする。Canvas Scaler は基準解像度 1920×1080・画面サイズ追従とする。画面には次を表示する。

| 表示 | 内容 |
| --- | --- |
| お題 | `表示文字列` |
| ローマ字表記 | 読みから生成した代表候補。許容入力の一例であり、唯一の正解ではない。 |
| 入力済み | 現在までの正解入力 |
| 残り | 代表候補に基づく未入力部分のガイド |
| ミス数 | `0 / 2`、`1 / 2` 等 |
| 残り時間 | `MiniGameBase.TimeRemaining` |
| 結果 | 成功・失敗理由。完了時に表示する。 |

## 7. 単体デバッグ環境

`Assets/Personal/Suzuki/Suzuki.unity` に、任意の `MiniGameBase` を単独起動できる `MiniGameDebugRunner` を配置する。起動対象、難易度、制限時間、結果表示を Inspector で差し替え可能にし、後から追加する別ミニゲームにも流用する。

## 8. 確認項目

1. 難易度に一致するお題だけがランダムに出題される。
2. `しんぶん` などで複数の許容表記を最後まで入力して成功できる。
3. 誤キー 1 回で進捗を保持したままミスが増え、0.2 秒中の入力が無視される。
4. 2 回目のミスで失敗が 1 回だけ通知される。
5. 制限時間切れが 1 回だけ通知される。
6. 日本語フォント割り当て後に、全 UI が意図した文字で表示される。

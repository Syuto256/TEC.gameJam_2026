## 追加時の要件

仕様書は機能ごとに Markdown ファイルを作り、企画書へのリンクを先頭に置いてください。

各仕様には、入力、状態遷移、成功・失敗条件、UI、永続化データ、例外ケース、確認方法を含めます。実装が始まったら、対応するクラスカタログまたは詳細設計ページへのリンクも追加します。

# メンバー試作からのミニゲーム UI 取り込み

日付: 2026-08-04  
状態: 実施済み

## 背景

本編のミニゲーム 4 本の画面は、静的 UI 化の際に暫定の見た目で組んだものだった。メンバーが各自の試作で作った UI と操作規則を本編へ取り込み、4 本の見た目をそろえる。

## 試作に何があったか

調べた結果、UI の完成度には大きな差があった。

| ミニゲーム | 場所 | 見つかったもの |
| --- | --- | --- |
| タイピング | `Assets/Personal/Suzuki/Suzuki.unity` | シーン上に完成した UI。お題・ローマ字・入力済み・残り・ミス・残り時間・結果の 7 要素 |
| なぞり | `Assets/Personal/Suzuki/TracingMiniGame/Scripts/` | シーンには UI 無し。ただしコード内に設計値（盤面色、マーカー色と半径、ガイド線の太さ、ミスは暖色・時間は寒色）があった |
| 仕分け | `Assets/Personal/Motonaga/Motonaga/minigame/` | 上端の残り時間ゲージ（Filled・緑）、カードと箱 100×100、ミス表示、ドラッグ規則 |
| 連打 | `Assets/Personal/Hiroto/` | Canvas は空。`Debug.Log` のみの試作だが、クリックとスペースキーの両方で数える規則があった |

## 取り込んだもの

**共通の並び**（4 本すべてに適用）

```text
上端        残り時間ゲージ（Motonaga）
左下・暖色  ミス表示（Suzuki）
下中央・白  操作の案内
右下・寒色  残り時間（Suzuki）
```

残り時間のゲージと数値は `MiniGameBase` が更新する共通機能にした。Prefab に置いて割り当てるだけで動き、各ミニゲームのコードは何も書かない。

**個別**

- タイピング: Suzuki の 4 段構成（お題／ローマ字／入力済み／残り）と日本語ラベル。従来は 1 つのテキストに色タグで入力済みと残りを混ぜていたが、試作どおり 2 つに分けた。
- なぞり: Suzuki の配色と寸法（始点＝緑、終点＝桃、現在地＝水色、ガイド線 16px）。
- 仕分け: Motonaga のゲージ、カード 100×100、掴んだカードを最前面に出す規則、不正解で元位置へ戻す規則。
- 連打: Hiroto のスペースキー規則。

**取り込まなかったもの**

- Suzuki のフォント（HackGen-Bold SDF）。本編は EnkaDotMincho24 SDF に統一済みのため、そちらに合わせた。
- Suzuki の結果テキスト。本編では結果確定と同時に Host が閉じるため表示される時間が無い。
- Motonaga の「ドラッグ中にカードを Canvas 直下へ付け替える」実装。ミニゲームが破棄されたときにカードだけが残るため、ミニゲーム内で並び順だけを変える形にした。
- Hiroto の「必要クリック数を 10〜100 でランダムに決める」規則。タスクレベルで難度を決める本編の作りと衝突するため、レベル連動のままにした。

## 表示範囲

`MiniGameHost` を PC / Tablet 両方の `DeviceFrame` に収まる最大の大きさへ広げた（844.8 × 669.6 → 1199.8 × 743.5、`Content` は 1167.8 × 711.5）。両端末枠の共通部分から内側に 20px の余白を取っており、どちらの面でも枠からはみ出さない。

## 検証結果

- 4 本すべてを実寸で描画して目視確認。Console エラー 0 件、EditMode テスト 11 件成功。
- タスク吹き出しからの実経路でタイピングが起動し、デバイス切替タブが両方とも非活性になることを確認。

## 併せて見つかった不具合

`GameTuningSettings.asset` の `difficultyProfiles` に、全項目が 0 の Easy の行が 1 つ入っていた。`maxHp = 0` のため**再生と同時にゲームオーバーになる**状態だった。Unity は Inspector でリストに行を足すと全項目を 0 にする（C# の初期値は使われない）ためである。

行の値をこれまでのフォールバックと同じ値で埋めるとともに、`GetDifficultyProfile` が 0 の項目を既定値で埋めた複製を返すようにして、同じ事故で進行不能にならないようにした。

## 残っている課題

- 日本語フォント `EnkaDotMincho24 SDF` に次の文字が無く、使うと豆腐（□）になる。フォントアセットの文字セットへ追加が必要である。

  ```text
  締 憩 怠 捗 緊 絡 押 違 込
  ```

  前半 6 文字はタイピングの問題文で見つかったもの、後半 3 文字は QTE / 目押しの文言を書く際に見つかったものである。とくに `押` は「キーを押す」「目押し」と書けないため影響が大きい。当面は `入力` `止める` など字形のある語で言い換えている。文言はすべて Prefab の Inspector に出ているため、フォントに追加した後はコード変更なしで書き換えられる。

- 残り時間ゲージは Unity 組み込みの `UISprite` を引き伸ばしているため、端がぼやける。専用のスプライトに差し替えると締まる。

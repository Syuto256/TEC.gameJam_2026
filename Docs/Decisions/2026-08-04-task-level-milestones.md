# タスクレベルの時刻表

記録日: 2026-08-04  
状態: 実装済み

## 決定

難易度プロファイルは `taskLevelMilestones` に問題レベルの到達時刻を持つ。時刻表が設定された場合は、従来の一定間隔設定より優先する。

Easy は 180 秒プレイを前提に、次の時刻表を用いる。

| 経過時間 | 生成する問題レベル |
| --- | --- |
| 0 秒 | Lv.1 |
| 60 秒 | Lv.2 |
| 120 秒 | Lv.3 |
| 150 秒 | Lv.4 |

## 互換性

既存プロファイルの時刻表が空の場合は、`startingTaskLevel`、`maxTaskLevel`、`taskLevelIncreaseIntervalSec` による従来の一定間隔方式を使う。

# ミニゲーム表示領域を共通化する

決定日: 2026-08-04  
状態: 合意済み

## 決定

`Game.unity` のミニゲーム表示領域は PC / Tablet の各ワークスペースに複製せず、共通 UI 配下の一つの `MiniGameHost` とする。

## 理由

- ミニゲームは選択したタスクに対して一件だけ表示するため、デバイスごとの Host は不要である。
- Host を一つにすると、Prefab の生成・破棄、入力の遮断、表示順を一箇所で管理できる。
- PC / Tablet ワークスペースは、デバイス固有の装飾、待機画面、タスク領域に専念できる。

## 影響

- `Shared` は HUD、デバイス切替、`MiniGameHost`、ポーズ等を保持する。
- `PcOnly` / `TabletOnly` は、各デバイス固有の画面とタスク表示だけを保持する。
- ミニゲーム中のデバイス切替を無効にするかは、既存の暫定案どおり実装時に確認する。

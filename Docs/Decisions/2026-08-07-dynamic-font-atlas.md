# 日本語フォントを Dynamic アトラスへ切り替える

日付: 2026-08-07
状態: 実施済み

## 背景

`EnkaDotMincho24 SDF` は **Static アトラス**（2048×2048・1544 字）で作られており、
焼いた時点の文字しか出せなかった。そのため次の 12 字が豆腐（□）になり、
**文言のほうを言い換えて回避していた**。

```
捗 押 違 込 締 憩 怠 緊 絡 択 企 了
```

とくに `押` が使えないため「キーを押す」「目押し」と書けず、
発注書 §11 は「完了」「誤り」を避けた表現になっていた。

## 当初案とその却下理由

**「HackGen をフォールバックに設定する」案が出たが、実測したところ効果がゼロだった。**

| フォント | 方式 | 上の 12 字のうち持っていない字 |
| --- | --- | --- |
| EnkaDotMincho24 SDF | Static | 捗 押 違 込 締 憩 怠 緊 絡 択 企 了 |
| **HackGen-Bold SDF** | Static | **架 縁 捗 押 違 込 締 憩 怠 緊 絡 択 企 了** |

**HackGen も同じ字を持っていない。** どちらも Static で、同じ範囲で焼かれていたためである。
フォールバックに足しても救われる字は 1 つも無い。

加えて、**両アセットとも元 TTF への参照（`m_SourceFontFile`）が外れており**、
その状態では Dynamic へ切り替えることもできなかった。

## 決定

**`EnkaDotMincho24 SDF` を Dynamic アトラスへ切り替える。**

1. 元 TTF `Assets/Fonts/EnkaDotMincho24.ttf` を `m_SourceFontFile` に紐づけ直す
2. `m_AtlasPopulationMode` を Dynamic にする
3. `m_IsMultiAtlasTexturesEnabled` を有効にし、1 枚に収まらなくなったら増やせるようにする

**HackGen はフォールバックに使わない。** EnkaDot 自身が自分の書体で足りない字を焼くため、
見た目が混ざらない。

## 結果（実測）

```
方式:   Static → Dynamic
字数:   1544 → 1556
アトラス: 1 枚 → 2 枚
```

`TryAddCharacters` で 12 字すべての焼き込みに成功した。
**避けていた語がすべて書けるようになった**ことを確認済み。

```
押す / 目押し / 締切 / 休憩 / 怠ける / 進捗 / 緊急 / 連絡
間違い / 書き込み / 完了 / 誤り / 選択 / 企画
```

## 限界

**元 TTF が持っていない字は、Dynamic でも出せない。** 実測したところ、
`EnkaDotMincho24.ttf` は次を持っていない。

```
♡ 〜 ─ │ ┌ € ™ / ギリシャ文字 / キリル文字 / ラテン拡張（À É など）
```

**現時点でゲーム本編のテキストには 1 つも使われていない**ため実害は無い
（`Prefab` / `Scene` / `ScriptableObject` の文字列 736 件を走査して確認）。

**これらを使いたくなったときは、そのとき初めて HackGen をフォールバックに足す。**
`HackGen-Bold.ttf`（11MB・プログラミング用フォント）はラテン・ギリシャ・キリル・罫線を
広く持っているため、その用途では有効である。手順は元 TTF を紐づけた小さな Dynamic
アセットを新規に作り、`fallbackFontAssetTable` へ足す。

## 影響

- **ビルドに `EnkaDotMincho24.ttf`（1.2MB）が含まれるようになる。** Dynamic は元 TTF を必要とする。
- 未収録の字が初めて画面に出るとき、アトラスへの焼き込みで**わずかな引っかかりが出る**可能性がある。
  多くの字を一度に出す画面があれば、事前に `TryAddCharacters` で焼いておく手がある。
- `m_ClearDynamicDataOnBuild` は `False`。Editor で焼いた字はアセットに残る。

## 併せて入れた小さな変更

| | |

| QTE | 正しく押した直後に次の警告が出るようにした（間隔を待たない）。テスト 2 件を追加 |

# 疑似 2D ライティングの技術検証を後工程へ延期

日付: 2026-08-04  
状態: TODO / 実装保留

## 決定

Game 画面の UI 構成、共有 Prefab 化、およびデザイナー素材の差し替え対応が完了した後に、暗い室内で PC / タブレット画面が発光する疑似 2D ライティングを技術検証する。現時点では画面構成やゲームロジックへ導入しない。

## 想定する検証範囲

- `Screen Space - Overlay` Canvas 上で、背景を暗くする Overlay と、選択デバイス画面の発光レイヤーを Image / CanvasGroup で合成する。
- PC / タブレット切替に合わせて、発光色・透明度・周辺の暗さを変化させる。
- 暗幕・発光レイヤーが UI 操作を阻害しないこと（装飾レイヤーの Raycast を無効化すること）を確認する。
- 必要になった場合のみ、より高度な UI Shader やアニメーションを検討する。URP の 2D Light を前提にはしない。

## 実施順序

1. Game 画面の PC / タブレット単画面切替と、タスク・ミニゲームの画面構成を確定する。
2. デザイナー素材を共有 Prefab に差し替え可能な形で反映する。
3. 上記が安定してから、代表的な PC 画面で疑似ライティングを試作する。
4. 視認性、操作性、素材との相性を確認して採用可否を決める。

この演出は現時点で確定仕様ではなく、画面構成を固めた後に評価する候補とする。

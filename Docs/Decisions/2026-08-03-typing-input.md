# タイピングミニゲームの入力判定方針

決定日: 2026-08-03  
対象: 今後追加するタイピングミニゲーム

## 背景

日本語の語句をローマ字入力するタイピングミニゲームを追加する。表示する問題文には漢字を含められる必要があり、同じ読みには複数のローマ字表記がある。

## 決定

- 問題データは、表示用文字列とひらがなの読みを別々に保持する。
- 読みのローマ字変換は、表記ゆれを許容する。初期実装から「し」の `si` / `shi` に加え、「ん」「っ」「きゃ」などの促音・拗音を含む日本語入力に対応する。
- 1 キーの誤入力を 1 ミスとして数える。2 ミスに達した時点でミニゲームを失敗として完了し、対応するタスクを解決不能として取り除く。
- 誤入力では、正しく入力済みの進捗を戻さない。誤った位置から再入力する。
- 誤入力の後、0.2 秒間はすべてのキー入力を完全に無視する。この間の入力はミス数・進捗のいずれにも影響しない。

## 実装上の方針

- 入力途中で複数のローマ字表記候補を保持し、入力がどの候補にも一致しない場合だけミスとする。
- 当面の ScriptableObject は表示用文字列とひらがなの読みを正とする。ひらがなからローマ字候補への変換結果を事前計算してアセットに保持するデータ形式・作成ワークフローは、基礎のゲームプレイ確認後に追加する。

## 保留事項

- 難易度ごとの出題数、単語の内容、ミニゲーム制限時間。
- ローマ字表記ゆれの詳細な許容表と、複数候補を保存する最終データ形式。
- 画面上での入力進捗・ミス・入力無効時間の見せ方と演出。

## 見直し条件

実機での入力感確認時に、0.2 秒の無効時間または日本語ローマ字表記の許容範囲が遊びにくさを生む場合は見直す。

# 仕分けミニゲームのレベル別レイアウト

記録日: 2026-08-04  
状態: 実装済み

## 決定

仕分けミニゲームは、Lv.1〜4 ごとに独立した Layout ルートを Prefab 上に持つ。各 Layout は、使う Card / Box UI Prefab インスタンス、位置、大きさ、正解カテゴリ、許容ミス数を個別に設定する。実行時には対象レベルの Layout だけを有効にする。

| レベル | 箱 | カード |
| --- | --- | --- |
| Lv.1 | A×1 | A×1 |
| Lv.2 | A×1 | A×3 |
| Lv.3 | A×1、B×1 | A×2、B×2 |
| Lv.4 | A×1、B×1、C×1 | A×1、B×2、C×1 |

## 理由

レベルごとの配置と見た目を Inspector 上で完全に独立して調整でき、カード／箱の素材差し替えも元 UI Prefab または各インスタンスの Override で行えるようにするため。

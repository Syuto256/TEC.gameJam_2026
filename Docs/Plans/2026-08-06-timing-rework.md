# 1. 仮素材を 6 枚作る

**発注書 §4 と同じ寸法・同じ名前で作ります。** 中身は白〜グレーの単純な図形で構いません。

| 名前 | 画素数 | ふち（9 スライス） | 中身 |
| --- | --- | --- | --- |
| `TimelineTrack` | 128 × 128 | **左右 48 のみ** | トラックの溝。横に長く伸ばして使う |
| `VideoClip` | 128 × 128 | **左右 48 のみ** | 映像クリップの塊 |
| `Waveform_A` / `Waveform_B` | 512 × 128 | なし | 音声波形。**左右の端がつながるように描く** |
| `Playhead` | 48 × 192 | **上下 48 のみ** | 再生ヘッド。縦に伸ばして使う |
| `CutZone` | 96 × 128 | **左右 32 のみ** | 成功範囲の帯。横に伸ばして使う |

置き場所: **`Assets/Sprites/InGameUI/MiniGameUI/Timing/`**

取り込み設定は**全部** Sprite (2D and UI) / **Pixels Per Unit 200** / ふちは表のとおり。

## ⚠ 波形は仮素材の時点で端をつなげてください

**横に敷き詰めて使う絵です。** 端がつながっていないと継ぎ目が見えます。
仮素材で手を抜くと、**本番の絵に替えたときだけ継ぎ目が消える**という分かりにくい差が出て、
「仮組みのときは変だったが原因が分からない」状態になります。

# 2. 作業領域を組む

## 現状

**`Track` の下に `TargetZone` と `Marker` があるだけの棒です。**
共通ウィンドウに入れた際に作業領域が狭くなったため、今は帯だけが残っている状態です。

## 目指す形

```
┌────────────────────────────────────┐
│ ┃                                          │  ← Playhead（縦・往復する）
│ ┃ ▓▓▓▓▓▓▓  映像トラック                  │  ← VideoClip を TimelineTrack の上に
│ ┃ ∿∿∿∿∿∿∿∿∿∿∿∿  音声トラック         │  ← Waveform を横に敷き詰める
│ ┃      ░░░░                                │  ← CutZone（成功範囲）
└────────────────────────────────────┘
```

- **トラックを 2 段**にする（映像・音声）。`TimelineTrack` を横に伸ばして溝にする
- 映像トラックに `VideoClip` の塊を置く
- 音声トラックに `Waveform_A` / `Waveform_B` を **`Image` の `Type = Tiled`** で敷き詰める
- `Marker` を `Playhead` に、`TargetZone` を `CutZone` に差し替える

## ⚠ `Marker` と `TargetZone` はコードが毎フレーム位置を書きます

**下の前提を壊すと動かなくなります。**（`TimingStopMiniGame.PickZone` / `ApplyMarker`）

| | コードが書くもの | Prefab 側で決めてよいもの |
| --- | --- | --- |
| `TargetZone` | `anchorMin` / `anchorMax` / `offsetMin` / `offsetMax` **すべて** | 絵・色だけ |
| `Marker` | `anchorMin` / `anchorMax`（横位置）と `anchoredPosition` | **`sizeDelta`（太さ）** |

- **どちらも「バー」を親にしたままにしてください。** 割合で位置を決めているので、
  親が変わると位置がずれます
- `TargetZone` は**幅も高さも上書きされます。** 大きさを Prefab で決めても消えます。
  **`CutZone` は左右 32 のふちがあるので、幅が変わっても角が歪みません**
- `Marker` は**縦に伸ばす**ので `sizeDelta.y = 0`（親と同じ高さ）、
  `sizeDelta.x` に太さ（24 前後）を入れてください

**この 2 つを別の親へ移したくなったら、先に報告してください。** コード変更が要ります。

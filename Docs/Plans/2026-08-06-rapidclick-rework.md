# 2. 作業領域を組む

## 現状

**`WorkArea` に何もありません。** 回数は `StatusBar/ProgressText`
（文字サイズ **22** / 枠 216×40）に `連打! {今の回数} / {必要回数}` として出ているだけです。

## 目指す形

```
┌──────────────────────────────┐
│  ┌────────────┐   character_01.png  │  ← ファイル名
│  │            │   1920 × 1080       │  ← 解像度
│  │  プレビュー  │   3 / 12            │  ← 何枚目か
│  │            │                     │
│  └────────────┘        残り 9        │  ← 大きい残り回数
└──────────────────────────────┘
```

- `PreviewFrame` を左側に置き、その中に `Preview_01` を出す `Image` を入れる
- 右側にファイル情報を縦に並べる（**ファイル名・解像度・何枚目か**）
- **残り回数を大きく出す**（文字サイズ 160〜200）。出すのは**数字だけ**、単位も見出しも付けない

**`StatusBar/ProgressText`（`連打! n / m`）はそのまま残してください。**
大きい数字は残り、小さい行は全体像、という役割分担にします。

**大きい数字は「残り回数」です**（`必要回数 − 今の回数`）。
`progressText` は「押した回数」なので**意味が逆**です。混同しないでください。

# 3. コードを足す — 1 回押すごとに切り替える

**5 種のうちコード変更が要るのはここだけです**（発注書 §12-2）。

`RapidClickMiniGame` に足すもの:

```csharp
[Header("【プレビュー】")]
[Tooltip("押すたびに切り替える画像。8 枚を順に使う。")]
[SerializeField] private Image previewImage;
[SerializeField] private Sprite[] previewSprites;

[Tooltip("ファイル名・解像度・何枚目かの表示先。")]
[SerializeField] private TMP_Text fileNameText;
[SerializeField] private TMP_Text resolutionText;
[SerializeField] private TMP_Text indexText;

[Tooltip("残り回数を大きく出す先。")]
[SerializeField] private TMP_Text remainingText;

[Tooltip("何回押すごとに切り替えるか。1 なら毎回。")]
[Min(1)] [SerializeField] private int switchEveryNClicks = 1;
```

- `Refresh()` の中で、今の回数から**何枚目か**を決めて差し替える
- 絵は `previewSprites[index % previewSprites.Length]`。**8 枚を周回して構いません**
  （発注書 §3: レベル 4 では 3 周するが、確認作業としてはむしろ自然）
- ファイル名・解像度は `[SerializeField]` の候補配列から選ぶ。**文字なのでいくらでも変えられます**

## ⚠ チカチカに注意

**レベル 1 で 12 回、レベル 4 で 24 回を数秒で押します。**
毎回切り替えると高速で点滅して見える可能性があります。

そのための `switchEveryNClicks` です。**既定は 1（毎回）**にしておき、
**目視で速すぎたら 2 や 3 に上げられる**ようにしてください。値は Prefab 側で決めます。

## 任意

大きい数字にも `RapidMashTextEffect` を付けると 1 回ごとに跳ねます。
**既に窓全体を揺らす `RapidMashTextEffect` がルートに付いている**ので、
二重に揺らすと読めなくなる可能性があります。付けるなら `strength` は小さめに。

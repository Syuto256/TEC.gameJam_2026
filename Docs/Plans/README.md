# 作業計画

**現在、進行中の計画はありません。**

ここは「合意済みの仕様を実装へ分解した段階計画」の置き場です。
複数の PR にまたがる作業を始めるときに、着手前の合意として 1 本置きます。

## 置く基準

**1 回の PR で終わる作業に計画は要りません。** 判断だけを [`Decisions/`](../Decisions/) に残せば足ります。
ここへ置くのは、次のどちらかに当てはまるときです。

- 段階が 3 つ以上あり、途中で確認ゲートを挟みたい
- 複数人で分担し、着手順の合意が要る

## 終わったら必ず動かす

**完了・撤回した計画は、その時点で [`Archive/`](../Archive/) へ移します。**
残したまま増やすと、古い記述と新しい記述が同じ重みで読まれます
（[振り返り §2-1](../Retrospective/2026-08-06-gamejam.md) — ジャムでは 3,385 行が現役のまま積み上がり、
資料が資料の訂正表を持ち始めました）。

手順は [`Archive/README.md`](../Archive/README.md) にあります。

# 1. ミニゲーム中の暗幕を消す

`FocusLightingView` の **`dimAlpha` を 0** にします。**Inspector の値 1 つです。**

窓のまわりを暗く落とす演出をやめ、デスクトップが見えるようにします。
**`glow`（窓のまわりの光）はそのままにしてください。** 影の絵に差し替える予定ですが、
絵が届いていないので今回は触りません。

> **⚠ QTE の作り直しが同じコンポーネントに触ります。**
> [QTE の作り直し](../Decisions/2026-08-06-qte-rework.md) 決定 8 で「光はダイアログごとに小さく出す」と
> しており、`FocusLightingView` を分解する可能性があります。**この節だけは、値の変更にとどめてください。**
> 構造を整理したくなったら、直す前に報告してください。

---

# 2. 明るさの段差をなくす

`RoomDimmer`（黒 α **0.42**）が **`Game` シーンにしか置かれていません。**
そのため蓋を閉じる演出でシーンが変わると、**一段明るくなって見えます。**

- 蓋の演出をまたぐシーン（`Title` / `DifficultySelect` / `Clear` / `GameOver`）にも同じ暗幕を置く
- **または** `Game` から外す

**どちらが正しいかは見た目の判断です。** 実際に蓋を閉じて確かめ、
**段差が消えるほうを採ってください。** 判断に迷ったら、両方の見え方を報告してください。

---

# 3. `win11Modoki` の縦つぶれ

PC 面で **10.4% 縦につぶれています**（液タブ側は 1.1% で、こちらは許容範囲）。

**`localScale` では直さないでください。** `RectTransform` の大きさを素材の縦横比に合わせます。

---

# 4. `DifficultySelectManager` を Canvas の外へ出す

`DifficultySelect.unity` の `DifficultySelectManager` が **Canvas 配下**にあり、
`localScale 2.377` / `localPosition (-1071, -484)` が付いています。

**ロジック専用の GameObject なので害はありません**が、
ドラッグで動かしてしまった跡に見えます。Canvas の外へ出し、
`localScale 1` / `localPosition (0, 0, 0)` に戻してください。

**参照が切れないことを確かめてください。** ボタンの `onClick` から参照されています。

# 6. フォントの欠字を埋める

**これだけ他と毛色が違います。** 分けたければ単独 PR で構いません。

`EnkaDotMincho24 SDF` に次の字形がありません。

```
架 縁 示 捗 押 違 込 締 憩 怠 緊 絡 択 企 誤 了
```

**これが原因で、文言のほうを避けて書いている箇所があります。**

- 発注書 §11 が「完了」「誤り」を使わず「保存しました」「入力が正しくありません」にしている
- `QteMiniGame.cs` に「`押` `違` は字形が無いため既定の文言では避けている」というコメントがある

アトラスに上の字を足してください。**文言を戻すのはこの PR ではやりません**（別途判断します）。
